# Android 手机控制台 0.3.0

电脑上运行 API 或 Codex 桌面包，手机安装 RoboMaster-Console-v0.3.0.apk（Android 8 或更高）。在桌面设置中先完成模型连接。手机复用电脑当前项目及其模型配置。两台电脑分别运行桌面包时，各自配对。

## 外网连接

1. 在电脑和手机上分别登录同一 Tailscale 私有网络，允许手机访问电脑的 HTTPS 服务。
2. 在电脑运行 `tailscale serve --bg http://127.0.0.1:49731`。按 Tailscale 的提示启用 HTTPS，复制它给出的 HTTPS 根地址。详见 [Serve 官方说明](https://tailscale.com/docs/features/tailscale-serve)。
3. 电脑打开当前项目的「设置 → 手机控制台」，填入上述地址，选择「操作当前项目」或「仅查看」，点击「生成配对码」。
4. 手机打开控制台扫码，或从相册识别二维码。两分钟内使用，并在电脑批准此设备。电脑可以单独撤销设备，也可以关闭服务并撤销全部授权。已有配对的电脑重启 Studio 后会重新监听本机端口。
5. 保持电脑清醒、Studio 运行，手机可通过移动数据连接同一项目。电脑切换项目后，手机仍能查看原项目，操作须等电脑重新打开配对的项目。

## 安卓操作

左右滑动内容区切换五个阶段，也可直接点击阶段名。前四页可输入消息，配合页有开始按钮。待确认问题在各页可见，回答会回到提出问题的阶段。项目规格、迭代证据和最近的 MCP 图片结果可在手机查看。有多个同类窗口时，手机提交到该阶段的首个窗口；所有窗口共享对话。

任务回执丢失时，手机保留操作编号，恢复连接后使用同一编号取回结果。手机锁屏、退出不会结束电脑任务。电脑意外退出时，运行中的回执标为「结果未知」，请先检查实际结果。已请求停止的 CAD 操作以电脑最终结果为准。

## USB 调试

在连接的安卓设备上运行 `adb reverse tcp:49731 tcp:49731`，在桌面配对地址输入 `http://127.0.0.1:49731`。USB 模式需要保持转发，外网使用上面的 HTTPS 地址重新配对。电脑服务只监听回环接口。模型凭据保存在电脑，手机只保存配对凭据和待确认的提交记录。

## 构建 APK

使用 JDK 17、Android SDK Platform 35、Build Tools 35.0.0 以及 Maven Central 的 `com.google.zxing:core:3.5.3`。运行 `scripts/build-android.ps1` 并指定 Jdk、Platform、BuildTools、Zxing 路径。可通过 Keystore、Alias 和环境变量 STUDIO_APK_PASS 指定签名。默认在本地 .local/android-signing 下生成签名，请备份以便以后原位升级。相机和相册只用于本机解码二维码。
