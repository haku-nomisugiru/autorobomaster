# RoboMaster Studio 0.3.0 手机控制台真机验收

2026 年 11 月 18 日，使用 Windows 上的 Rust 桌面版和已安装发行 APK 的 PLR110 安卓手机完成测试。API 版与 Codex 版的桌面可执行文件 SHA-256 相同。

| 场景 | 操作与结果 |
| --- | --- |
| 配对 | 手机从相册识别桌面生成的一次性二维码，桌面批准设备后，手机显示「已连接」及项目名。本次使用相册入口，未实拍相机扫码。 |
| 五阶段切换 | 手机上依次左右滑动内容区，核对需求、检索、原型、验收和配合的页面标题。 |
| Codex 外网对话 | 关闭手机 Wi-Fi，保持移动数据与 Tailscale 开启，移除控制台的 USB 端口转发。手机向桌面发送 `Reply with OK`，收到了桌面 Codex 的 `OK`。 |
| 外网点选与重试 | 手机发消息让 Codex 提供 Alpha 和 Bravo 两个选项，随后点选 Bravo。测试分别截断消息和点选的首次成功回执。每个操作都抵达电脑两次，两次使用相同的操作编号。桌面数据库中各有一条完成记录，项目里只有一条点选、一条最终回答和一条对应的偏好技能。手机显示「你选择了 Bravo。」 |
| API 版断线重启 | 使用本地模拟模型和真机，分别在消息和点选的首次回执丢失后断开 USB 转发，强制退出并重开手机控制台。恢复转发后两项操作都完成，模型共收到两次调用，对应消息和点选各一次。 |
| 两端重启 | 桌面空闲时关闭测试窗口，从发行包的正常启动入口重新打开 Codex 版，同时重开手机控制台。手机沿用原配对自动连接，重新取回最终回答。 |

测试结束后，Tailscale 私网 HTTPS 入口已恢复直接连接 Studio，公网 Funnel 关闭。移动数据测试期间，USB 仅用于操作和观察手机。模型交互验收到对话和点选为止，未执行实际的 SolidWorks 文件写入。

若电脑恰好在 CAD 操作执行途中退出，Studio 会把该操作标为「结果未知」。恢复后先检查模型与任务记录，再决定是否重新提交。
